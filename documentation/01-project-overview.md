# 01 - Project Overview

## Introduction

The purpose of this project is to assess, redesign, and improve the security of an existing home network through hands-on networking and cybersecurity exercises.

Using Kali Linux and various networking tools, I will identify connected devices, examine exposed network services, monitor network traffic, and evaluate potential security weaknesses.

After completing the initial assessment, I will design and implement improvements to the network architecture with the goal of creating a more secure and organized home network.

A virtual representation of both the original and redesigned networks will also be developed in Cisco Packet Tracer to explore network architecture, device communication, and security configurations.

This repository documents the entire process, including configurations, commands, scan results, observations, troubleshooting, and security improvements.

## Project Objectives

- Map the structure of an existing home network.
- Identify connected devices and their manufacturers.
- Discover open ports and running services.
- Analyze network traffic using Wireshark.
- Develop and maintain a network device inventory.
- Recreate the original network in Cisco Packet Tracer.
- Identify potential security weaknesses.
- Design a more secure network architecture.
- Implement appropriate security improvements.
- Verify the effectiveness of the changes.

## Project Phases

### Phase 1: Initial Network Assessment

Discover connected devices, examine exposed services, and document the existing network configuration.

### Phase 2: Network Monitoring and Analysis

Use Nmap and Wireshark to investigate network activity and identify potential security concerns.

### Phase 3: Network Simulation

Recreate the existing home network in Cisco Packet Tracer to understand its architecture and communication paths.

### Phase 4: Security Assessment and Redesign

Evaluate the original network and develop a more secure architecture incorporating appropriate network segmentation, access controls, and device isolation.

### Phase 5: Implementation and Verification

Apply the redesigned configuration to the actual network where supported, then repeat the initial assessment to evaluate the improvements.

| Tool | Purpose |

## Expected Outcome

The final outcome will be a documented and improved home network architecture.

The project will include an assessment of the original network, a redesigned network topology, implementation of security improvements, and a comparison of the network before and after the changes.

## Safety and Scope

All testing will be limited to networks and devices that I own or have explicit permission to assess.

Sensitive network information, credentials, and private packet captures will not be published.
