##  Project Overview

This project explores the security of a real home network using Kali Linux and various networking tools. The goal is to identify connected devices, examine exposed network services, analyze network traffic, and understand potential security weaknesses.

A virtual representation of the network is also being developed in **Cisco Packet Tracer** to explore network architecture, device communication, and connectivity.

This repository documents the entire process, including configurations, commands, scan results, observations, troubleshooting, and security recommendations.

##  Objectives

- Discover devices connected to a home network.
- Identify device manufacturers and IP addresses.
- Examine open ports and running services.
- Analyze network traffic using Wireshark.
- Develop and maintain a network device inventory.
- Recreate the network in Cisco Packet Tracer.
- Identify potential security concerns.
- Apply and document security improvements.

##  Safety & Scope

This project is intended for educational use on networks and devices that I own or have explicit permission to assess.

All publicly shared network information is sanitized. Private IP/MAC addresses, hostnames, credentials, and sensitive packet captures should not be published.
